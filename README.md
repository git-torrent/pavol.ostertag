# Pavol Ostertag — Software Architecture Consultant

Personal GitHub Pages site for Pavol Ostertag, an IT Software Architect Consultant focused on architecture direction, pragmatic modernization, and systems thinking.

## Publish with GitHub Pages

1. Push the contents of this folder to a GitHub repository (or place them in that repository's `/docs` folder).
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the branch and either `/ (root)` or `/docs` as the folder.

The site is plain HTML, CSS, and JavaScript, so no build step is required.
